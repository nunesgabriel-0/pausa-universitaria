# pausa-universitaria
Site interativo de promoção da saúde mental para estudantes universitários.

O que é esse projeto
O Pausa Universitária é um projeto acadêmico que propõe o desenvolvimento de um site interativo voltado à saúde mental de estudantes universitários, com foco em estresse, sobrecarga acadêmica, emoções e hábitos saudáveis. Mas o site terá caráter educativo e não realizará diagnósticos nem substituirá acompanhamento psicológico ou médico.

Objetivo
Disponibilizar informações educativas, atividades interativas e orientações que ajudem estudantes a compreender suas emoções, desenvolver hábitos saudáveis e encontrar informações sobre ajuda profissional.

Funcionalidades previstas
Conteúdos educativos sobre emoções e estresse.
Exercício guiado de respiração.
Quiz educativo sobre emoções.
Checklist de hábitos saudáveis.
Organizador de estudos e pausas.
Informações sobre onde buscar ajuda profissional.

Tecnologias previstas
HTML
CSS
JavaScript
